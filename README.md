# LifeSimulator · 我的人生平行世界

> 构造一个关于我人生的平行世界。现在也是 2026 年 10 月 1 日，平行世界里的我也在放假休息。它从我的当前状态出发，我可以添加或调整变量，再看看一个月、一年后会是什么样子。

这就是项目的方向：**可编辑、可解释、能反复推演的个人生活模型**。网页只是观察窗口；生活状态、行为选择与时间推进都由真实 C++ 行为树计算。

[打开网页模拟器](https://frankwang98.github.io/LifeSimulator/)

## 现实时间、小人与生活场景

默认进入“与现实同步”：按 **Asia/Shanghai（北京时间）** 显示年月日和时分秒，时钟每秒更新。模型仍按小时决策；跨小时或重新打开网页时，C++ 从世界起点确定性重算到现在，读取该小时的真实执行轨迹，不需要网页一直开着。

人物可以选择男或女，性别只影响外观，不改变收益、代价或决策。2D SVG 场景与 C++ Action 对应：卧室（睡眠、休养）、办公室（工作）、书房（学习）、户外运动区（运动）、客厅（陪伴、休闲）。动画只是行为的可视化，不是另一套模拟规则。

现实模式的状态卡片显示本小时开始时的状态，不提前计入这一整小时的收益；当天行为统计只包含已经完成的小时。行为树展示当前小时选中的行为和判断条件。点击“未来推演”后可以选日期、按小时回放，再一键回到现在。

**当前世界与未来方案独立**：首次打开时，以现有个人设定初始化当前世界；以后当前世界设定单独保存在浏览器。“生成平行世界”只更新未来方案，“应用到当前世界”才会更新现实同步的世界。当前世界更改参数后仍从起点重算，不是从现在创建新的时间分支。

连续休假从世界起点计算，不会在每次刷新时重新开始。若起点在现实日期之后，页面明确显示“尚未开始”，不伪造人物行为。离线期间的进度由重算恢复；没有服务端后台进程。浏览器设备时钟是时间来源，不校准设备时间，当前模型支持从起点最多十年。

## 这一版能做什么

- 从 **2026-10-01** 起步，按真实公历日期推进；默认连续休假 7 天，然后周一至周五工作。
- 调整健康、现金、负债、时薪、支出、工作时长、运动／学习／陪伴间隔等变量。
- 推演 30 天、365 天或 1095 天，对比“初始世界”和“修改设定后的平行世界”。
- 查看每天的时间分配、日末状态，以及趋势曲线。
- 选中某一天、某一小时，回放 **Selector → Sequence → Condition → Action** 的实际运行。
- 看到每个节点的 SUCCESS / FAILURE、哪些分支未访问、行动前后的状态变化。
- 在浏览器本地保存设定，支持 JSON 导入与导出。没有账号、服务端和个人数据上传。

连续休假是用户可修改的假设，不是官方节假日表；目前也没有调休上班规则。真实日期解决了原版“第零天直接当星期一”的问题。日末卡片不是实时状态；逐小时视图单独显示 tick 前后的状态。

## 网页确实在运行 C++

不是用 JavaScript 重写一遍规则，也不是播放固定的 CSV。

`src/wasm.cpp` 把同一个 C++ 核心编译为 WebAssembly。网页把设定送给 Web Worker，调用 `simulate_world()`，C++ 返回日末结果、行为树结构和选定一天的逐小时执行记录。JavaScript 只负责输入、绘图和回放。

事件记录直接产生在 C++ 的节点 `tick()` 中。灰色分支表示没有被访问，不会根据行动结果猜测状态。每小时都从根节点重新选择一个行为；当前动作是一小时原子动作，只有 SUCCESS / FAILURE，还没有跨 tick 的 RUNNING、异步动作与 halt。

当前是手写的轻量 C++ 行为树内核，**并非 BehaviorTree.CPP**；原来的 BT.CPP 导航例子仍保留在 `examples/navigation/`。自动驾驶方向由 ros2drive 承载。

## 从我的当前状态出发

网页中的数值是演示默认值，不是经过校准的个人数据。初始世界的默认年龄 28 岁、现金 0、负债 30 万，健康等评分需要自己调整。

1. 填写目前的状态和你想改变的条件。
2. 选择未来 30 天、一年或三年。
3. 点击“生成平行世界”。修改后不会偷偷影响已显示的结果。
4. 拖动日期，观察差距如何累积。
5. 在逐小时回放中查看“为什么此刻选择休闲，而不是工作”。

初始世界和平行世界使用相同的起点日期和推演时长；初始世界其他设定保持 C++ 默认值。第一版只能改变**已有模型变量**，还不能随意添加新的行为、任意公式或突发事件。网页刷新可以恢复最近生成的设定。

## 当前模型假设

| 行为 | 效果 |
|---|---|
| 睡眠 | 提升精力，略微恢复健康；固定夜间睡眠，低精力也会触发 |
| 休养 | 健康低于 35 时优先恢复，额外花费每小时 15 元 |
| 工作 | 基础时薪 × (1 + 知识 / 100)，消耗精力、健康和幸福 |
| 运动 | 提升健康和幸福，消耗精力 |
| 学习 | 增加知识，消耗精力 |
| 陪伴 | 提升关系和幸福，少量消耗精力 |
| 休闲 | 恢复精力，提升幸福 |

最低活动保障：运动、陪伴至少每 48 小时检查一次，学习至少每 72 小时检查一次。睡眠与紧急休养仍可优先覆盖这些活动；不存在绝对保证。

| 策略 | 工作上限 | 活动安排 |
|---|---|---|
| 均衡 | 设置的基础工作时长 | 使用设置的运动、学习、陪伴间隔 |
| 健康 | 基础时长减 2 小时，最低 0 | 使用设置的活动间隔，留出更多空闲时间 |
| 赚钱 | 基础时长加 2 小时，最高 12 | 只保留最低活动保障 |

每天结算：生活支出、自然健康／幸福／关系衰减和债务日计息；每 30 天将超过现金储备的部分用于还贷。现金可以为负，代表未覆盖的支出，不自动计入新贷款。收入是按工作小时计费，**休假没有工作收入**，不是现实月薪制。知识增益对收入的影响也只是演示假设。

这是比较假设的实验，不是人生预测。尚未建模真实疾病、失业、婚姻互动、就业门槛、死亡、税费与通胀；当前评分也没有现实统计校准。

## 原生 C++ 使用

需要 C++17 编译器与 CMake 3.16+，核心无第三方依赖。

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
ctest --test-dir build --output-on-failure

# 默认世界，三种策略，导出逐日 CSV
./build/life_tree --strategy all --days 365 --output output

# 使用个人设定，返回 JSON（包括指定一天的逐小时轨迹）
./build/life_tree --config examples/worlds/my-world.conf --json > world.json
```

设定文件使用 `key=value`，网页 WASM 与原生 CLI 使用同一解析器。完整示例在 [`examples/worlds/my-world.conf`](examples/worlds/my-world.conf)。`trace_day=8` 会记录第八天的 24 个 tick；只保留指定一天的轨迹，避免长期推演占用过多内存。原生支持 1—3650 天。

## 构建网页

需要 Emscripten 和 Node.js。GitHub Pages 工作流自动编译、测试、发布。

```bash
bash scripts/build_web.sh
node tests/test_web.cjs
python3 -m http.server 8000 --directory docs
# 打开 http://localhost:8000
```

`engine.js` 和 `engine.wasm` 是编译产物，不提交到仓库；Pages 发布时自动生成。不能直接双击 HTML，需要 HTTP 服务加载 Worker / WASM。页面如果无法加载 C++ 引擎，会明确提示失败，不会切换到虚构的 JavaScript 模拟结果。

## 代码结构与验证

| 文件 | 职责 |
|---|---|
| `src/calendar.h` | 公历日期、星期、闰年 |
| `src/state.h` | 个人状态 Blackboard 与事件 |
| `src/bt.h` | Selector / Sequence / Condition / Action |
| `src/config.h` | 个人参数、解析与范围校验 |
| `src/life.h` | 生活行为、行为树构建、时间推进 |
| `src/json.h` | 统一结果和轨迹序列化 |
| `src/main.cpp` | 原生 CLI 与 CSV |
| `src/wasm.cpp` | 浏览器调用入口 |
| `docs/worker.js` | 在 Worker 中调用 C++ 引擎 |
| `docs/app.js` | 现实／未来模式、表单、曲线与轨迹回放 |
| `docs/time.js` | 北京时间和跨日期计算 |
| `docs/scene.js` | C++ 行为对应的男女角色和场景 |

测试覆盖时间／现金守恒、可复现性、优先级、日期／休假、参数对结果的影响、轨迹和短路执行。`tests/test_web.cjs` 将原生 C++ 与浏览器 WASM 的结果逐字段比较，包含所有节点事件与小时状态，同时验证错误参数。

C++ 统一使用 `.clang-format`：Google 基础样式，2 空格，100 列；CI 使用 clang-format-18。

```bash
clang-format-18 -i src/*.h src/*.cpp tests/*.cpp examples/navigation/src/*.h examples/navigation/src/*.cpp
```

## 想要走到哪里

1. **更像我的日子**：记录真实日程、休假、睡眠、收支，手动同步当前状态，为参数校准提供依据。
2. **更多平行世界**：保存多个分支，在某个日期修改条件并继续推演，而不是每次都从起点重算。
3. **环境和事件**：失业、疾病、机会、家庭变化；使用固定随机种子和多次模拟，看结果分布。
4. **更丰富的决策**：长时间任务与 RUNNING / halt，必要时引入 BehaviorTree.CPP、Utility AI 或规划模块。
5. **更完整的社会**：先扩展家庭，再考虑多个 Agent；保持每一次决策都可回放、可解释。

先把一个人的生活模型做可信、做透明，再增加技术和复杂度。保留“为什么做这个选择”的证据，比网页装饰更重要。
