模拟的起点和规则

28 岁，现金 0 元，负债 30 万元。生活支出每天 120 元，债务年利率 4%，每 30 天将超过 3000 元现金储备的部分用于还贷。

三种策略每日工作上限分别为 10、6、8 小时，周末不工作。工作带来收入，也消耗精力和健康；学习积累知识，运动和陪伴改善状态。

这是确定性规则实验，评分与收益是演示假设，不是人生预测。第一版暂不包含失业、疾病等突发事件，也不能修改初始参数。
